# Sensor API Project

Простий локальний API на PHP (з використанням Composer) для видачі даних промислових датчиків та консольний клієнт на Python для їх отримання.

## Структура
* `api/` — серверна частина (PHP, маршрутизатор `bramus/router`, дані у `data.json`).
* `client/` — клієнтська частина (Python, бібліотека `requests`).

## Як запустити

### 1. Запуск сервера (API)
Перейти у папку `api`, встановити залежності та запустити локальний сервер:
```bash
cd api
composer install
php -S localhost:8000
